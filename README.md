# Sklad.io — версія для хостингу

React + FastAPI за одним HTTPS-посиланням; PostgreSQL у Neon; Render Free.

Інформаційна система обліку товарів на складі. Автор: Кобзей Олександр Юрійович, ІПЗ-41. Дисципліна: Професійна практика. Викладач: Микола Пікуляк.

36 автоматичних перевірок PASS; production build і локальний браузерний сценарій перевірено. Архітектура використовує Repository та Factory Method, атомарні операції руху товарів, ролі Admin / Storekeeper / Manager, Argon2 і JWT.

Повна інструкція: DEPLOY_UA.md. Конфігурація: render.yaml. Збірка: Dockerfile. API працює під /api, документація /api/docs, перевірка стану /health.

Початковий адміністратор: admin@sklad.io. Пароль задається змінною ADMIN_PASSWORD у налаштуваннях Render. JWT_SECRET генерується Render, DATABASE_URL надає Neon. Секрети не входять у файли проєкту.

Локальні перевірки: python -m pytest tests -v. Браузерний протокол та результат тестів — evidence/. Docker-build локально не перевірявся, оскільки Docker відсутній. Фактична перевірка хмарного розгортання виконується після підключення сервісів.

Безплатний Render засинає після 15 хвилин; перше відкриття може тривати близько хвилини. Дані в зовнішньому Neon зберігаються при перезапуску застосунку в межах тарифних квот.
